# Datos del registrador

Rama escrita por GitHub Actions (`.github/workflows/collect.yml` en `main`). No editar a mano.

- `status/AAAA-MM.jsonl`: estado oficial del paso, una línea por hora.
- `forecast/AAAA-MM.jsonl`: pronóstico Open-Meteo (Las Cuevas, Portillo), cada 6 h.

Timestamps `fetched_at` en UTC.
